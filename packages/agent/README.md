# Vittaz Agent Package

## Overview

Package boundary for `@vittaz/agent`, encapsulating LLM providers, tool calling harnesses, LangChain isolation, and assistant services for Vittaz.

## Subdirectories & Boundaries

- [src](./src/README.md) - Agent engine source files including key pool, provider client, tools, Q&A loop, LangChain bridge, local model tasks, and Telegram connector.
