# Vittaz Applications

## Overview

Top-level container for all user-facing client applications in the Vittaz repository. Encapsulates delivery channels including the terminal CLI, the Expo / React Native mobile app, and the isolated mobile web preview.

## Subdirectories & Boundaries

- [cli](./cli/README.md) - Command-line interface package (`@vittaz/cli`) for ledger operations, backups, and automation.
- [mobile](./mobile/README.md) - Expo / React Native mobile app (`@vittaz/mobile`) and isolated web UI preview (`@vittaz/mobile-ui`).
